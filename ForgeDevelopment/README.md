# ForgeDevelopment

给地图作者用的可选诊断包：观察关卡生成、空间、性能和异常，记录证据并输出报告。普通玩家不需要它，也不要把它装进玩家的模组档。

在 r2modman 或 Thunderstore 模组管理器里安装，会一并装上 GTFO_API 和 ForgeCore；不需要 ForgeEngine，原版、MTFO 和 Forge 关卡都能用。配置键、记录器、抓取方法、离线工具和边界见[开发者指南](https://github.com/NAinfini/GTFO-Forge-Mods/blob/main/ForgeDevelopment/DEVELOPERS.md)。

问题请到 [GitHub](https://github.com/NAinfini/GTFO-Forge-Mods/issues) 反馈，或在 GTFO Modding Discord 找 **nainfini**。
