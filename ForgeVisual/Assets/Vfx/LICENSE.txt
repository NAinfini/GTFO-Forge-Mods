Forge effect assets: licenses
=============================

Everything in this folder except forge-visual-fx.bundle (below) is CC0 1.0 (public domain dedication):
https://creativecommons.org/publicdomain/zero/1.0/
forge-vfx.manifest.json lists every asset inside forge-vfx.bundle with its SHA-256, source, author, license, origin and
modifications.

forge-vfx.bundle
----------------
Built with Unity 2019.4.21f1 from Tools/Vfx/ForgeVfx. It holds only Forge's own work: the effect prefabs, the
particle shaders and the self-made textures, materials and meshes.
Author: Forge. CC0 1.0. Generated by Tools/Vfx/ForgeVfx/Assets/ForgeVfx/Editor/ForgeVfxOwnEffects.cs; no
third-party file is inside the bundle.

forge-visual-fx.bundle
----------------------
The heavy-weapon explosion every package that fires one shares. Built with Unity 2019.4.21f1 by the effect library
(Tools/Vfx/FxLibrary/fx_slots.py); it holds effects rebuilt from Unity Asset Store packs under the Standard Unity Asset
Store EULA, which allows shipping them inside a built product. They are shipped only inside that built bundle; the
packs' source files are not redistributed and are not in this repository. fx-licences.forge next to the bundle lists
every pack used, its recorded licence and the effects taken from it.
