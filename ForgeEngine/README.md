# Forge Engine

The game side of Forge. It loads the content packs that Rundowns and mods ship, runs them in step with the game and keeps everyone in a multiplayer game on the same version. It changes nothing in a stock level until a Rundown or mod ships content for it.

Install with r2modman or the Thunderstore Mod Manager, or let a Rundown or mod that asks for it pull it in. It needs BepInExPack_GTFO, GTFO-API, MTFO and ForgeCore; r2modman installs these for you. The settings, the logs to attach to a bug report and the interfaces are in the [developer guide](https://github.com/NAinfini/GTFO-Forge-Mods/blob/main/ForgeEngine/DEVELOPERS.md).

Report bugs on [GitHub](https://github.com/NAinfini/GTFO-Forge-Mods/issues), or find me on the GTFO Modding Discord as **nainfini**.
