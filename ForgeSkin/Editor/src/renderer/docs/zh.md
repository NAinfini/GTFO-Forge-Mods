# 皮肤是什么、装在哪 {#what}

ForgeSkin 由两样东西组成：

- **ForgeSkin 插件**：装在游戏的 r2modman 配置档里，进游戏后把皮肤套到你的枪、近战、工具和物品上。
- **这个编辑器**：做皮肤、看预览、一键装进游戏、打包分享。

几个要点：

- 皮肤**只在你自己电脑上生效**。别人看到的是他们自己装的皮肤，不联机同步。
- 做好的皮肤打成一个 `.forgeskin` 皮肤包。编辑器把它装进配置档的 `BepInEx/plugins/ForgeSkin/skins` 文件夹。
- 配置档要先装好 **BepInExPack_GTFO**。插件和它需要的 ForgeCore 由编辑器在「应用到游戏」时自动装，不用自己下。
- 进游戏后在**大厅点 SKINS 按钮**，给每件装备挑皮肤、给皮肤换玩家颜色。关卡里打不开这个界面。

下一步：[新建皮肤与选武器](#start)。

# 新建皮肤与选武器 {#start}

**选装备**：点 3D 视图左上角的装备名（或按 `Ctrl+P`），弹出全部武器、工具和物品。上面能搜索，下面的小标签按栏位筛选。点一张卡片就换过去。

**每件装备可以有好几个皮肤**。左边竖条点「皮肤」，看到这件装备的全部皮肤卡片：

- 点卡片切换到那个皮肤。
- 「新皮肤」卡片：**新建空白皮肤**、**复制当前皮肤**、打开工程或旧版预设（`Ctrl+O`）、导入 Skins 皮肤组。
- **导入 Skins 皮肤组…**：选皮肤组文件夹里的 `manifest.skingroup.json`。组里写了几把武器，就给每把武器各建一个皮肤（一条材质设置适用几把就各放一份）；贴图宏（如 `@NORMAL`、`@CHECKER(...)`）会换成小图片放进来。组里没写武器 ID 的（只写了关卡条件的也算），在 Skins 里不会套到任何武器上，编辑器会让你挑一把武器再导入，或者取消。导入后弹出一份清单，列出没带过来或被改写的内容（换网格、部件位置、第一人称设置、Vector 属性、别的着色器、关卡条件、缺的贴图文件、同一材质的重复设置等），点开就能看到每一项。
- 卡片上的「更多」：改名、复制、保存为文件、版本快照、清空当前改动、删除。双击名字也能改名。
- 卡片上标着「游戏中」的，就是游戏现在用的那个。

皮肤随改随存，不用担心丢（见 [保存、导出、装进游戏](#save)）。

# 贴图 {#textures}

先在左边「部件」列表点一个部件（或在 3D 里直接点），右边竖条点「贴图」。每个材质有四个格子：

| 格子 | 管什么 |
| --- | --- |
| 基础色 | 表面颜色和图案，最常换的就是它。 |
| 法线 | 凹凸细节。按常见的切线空间法线图做就行，打包时编辑器会转成游戏要的排布。 |
| 金属/光滑 | 金属感和光泽，对应游戏材质的金属/光滑贴图（游戏装备着色器的排布：红色通道是金属度，绿色通道是光滑度）。 |
| 自发光 | 会发光的部分。换了之后可以调发光颜色和强度，「应用到全部部件」一次改全枪。 |

**换图的方法**

- 点格子选一张图，或把图片拖到格子上。格子右上角从「原版」变成「已替换」就成了；点 × 恢复原版。
- 整把枪一次换：把一个文件夹拖进窗口，或在「概览」里点「整枪文件夹」。文件名里带部件名和通道名（比如 `Receiver_BaseColor.png`）就能认出来；没把握的会标黄，等你点「正确」确认。
- 在 Photoshop、Substance Painter 里改了图存盘，编辑器会自己重新读。
- 「发布」菜单里有导出 OBJ 模型和 UV 模板图，方便在别的软件里画。

**格式与尺寸**

- 能用的图片：png、jpg、jpeg、tga、tif、tiff、bmp、webp。打进皮肤包时统一转好。
- 输出尺寸在「应用到游戏」旁边的「更多」里选：保持、原版、1K、2K、4K（按长边，始终保持比例）。
- **单边超过 8192 像素的图游戏读不了**，整个皮肤包会被拒。尽量用 2 的幂次尺寸（1024、2048……）。
- 贴图越大越占显存。概览里会显示这个皮肤在游戏里大约占多少显存：256 MB 以内算轻，超过 512 MB 可能让游戏卡顿。

# 涂装与动态图层 {#layers}

不想自己画贴图，也能直接在编辑器里上色。选中部件后：

**涂装**（右边竖条「涂装」）像赛车游戏的涂装编辑器：

- **漆面**：哑光、亮面、金属、镀铬、碳纤维、发光等，决定部件看起来多金属、多亮。
- **底漆**：整片上色。混合方式选「正片叠底」可以保留原贴图的细节。
- **贴花**：贴一张图或贴纸，在 3D 里按住部件拖动，它会顺着表面滑动。
- **笔刷**：在 3D 里直接画，可选自由画、直线、圆和填充整块。
- **花纹**：迷彩、大理石、蜂窝、火焰等几十种预设。
- **磨损**：按边缘、凸起和随机斑块磨掉上面的漆。「随击杀磨旧」填大于 0 的数，枪会随击杀分四档慢慢变旧。
- 每层都能调透明度、混合方式，还能用「画遮罩」把某些地方挡住。列表里越靠上的层盖在越上面。

打包时涂装会烘进贴图，游戏看到的就是普通贴图。

**动态图层**（右边竖条「动态」）是会动的贴图：图片、序列帧、视频、文字。可以一直显示，也可以在击杀、命中、开火、装备等事件时播放；播放方式有循环、播放一次、循环 N 秒。视频按帧率拆成图片，最多 240 帧。帧数多、尺寸大的动态图层最占显存。

**代码特效**（部件右边的「+」→「代码特效」→「在这个部件上画动态花纹」）是游戏实时画出来的会动的花纹：流光、扫描线、脉冲、噪声、边缘光、极坐标花纹，一个皮肤最多 8 个。可以画进部件的底色或发光，盖在贴图和动态图层上面；也可以在「画在」里改成画在挂件模型上。每种花纹有自己的滑条和颜色，再加大小、旋转、转速、强度和叠加方式；也能只在击杀、开火等事件后亮几秒。勾上某项旁边的「玩家可调」，玩家就能在游戏里 SKINS 界面的「调整」页改它，改的结果只存在他自己电脑上。3D 预览和游戏用的是同一份花纹代码。
# 挂件 {#attach}

挂件是装在枪上的额外东西。选中部件，右边竖条点「挂件」→「添加挂件」：

- **弹药屏**：实时显示数字，详见 [弹药屏](#screen)。
- **导入模型（.glb）**：任何 .glb 模型都能挂。
- **全息形状**：线、球、圆环、弧、方块、网格、圆柱、圆锥、面板。

新挂件挂在当前选中的部件上，之后可以改挂到别处。在 3D 里按 `G` 移动、`R` 旋转、`S` 缩放；打开「贴到表面」后点枪身，挂件直接贴到点的位置。

选中挂件后，「特效」里可以加**闪光**或**显示**：比如每次击杀闪一下，或者只在瞄准时显示。部件的「位置」里还能移动、隐藏部件，或换成你自己的模型。

**音效**：「音效」里给击杀、弹药不足、倒地、被救起等时刻配声音，每段最长 10 秒，只有你自己听得到。「添加音效」先选事件再选文件。同一事件可以放好几条，每次随机播一条，「权重」越大越常被抽到，同一条不会连着播两次；组标题上的随机按钮照游戏的规则试听。击杀还可以按具体敌人各配一组：在音效的「哪个敌人」里选（列出游戏数据里的全部敌人，显示准确名称，可输入搜索），击杀这个敌人时改播那一组，没配的敌人照常播「任意敌人」那组。倒地和被救起只给你当时拿在手里的那件装备播放。

# 弹药屏 {#screen}

弹药屏是挂在枪上的一块小屏幕。添加后在右边「屏幕」里设置：

- **显示什么**：弹匣内子弹、备弹、总弹药、击杀数、造成伤害（本武器 / 全部武器）、受到伤害、命中率 %、血量 %、感染 %，或者固定文字。
- **样式**：数字或进度条；位数可以自动，也可以固定 1 到 6 位，可选补零。
- **字体**：本机字体或自己选一个字体文件。
- **颜色**：面板、边框、数字颜色和发光；「游戏里发光」决定进游戏后亮不亮。
- **低弹药变色**：弹药低于设定比例（默认 20%）时换颜色，也可以接近时渐变过去。

点 3D 视图下面的「模拟开火」「模拟击杀」等按钮，能看到屏幕上的数字跟着变。

# 玩家可换色 {#colors}

你可以让玩家在游戏里自己给你的皮肤换颜色。

- 在颜色设置旁边点**小人按钮**，这个颜色就变成「玩家可调颜色」。
- 不选任何东西时，右边「概览」里有「玩家可调颜色」列表：起名字、设默认色、加几个**推荐色**。
- 一个可调颜色可以同时管几处，比如枪身染色和屏幕数字，它们总是一起变。能管的地方有：染色、发光、挂件颜色、屏幕数字、面板、边框、低弹药色、特效闪光色。

进游戏后，大厅 SKINS 界面的「颜色」页就能换：先列出你给的推荐色；没给推荐色就是一排 12 个色相；也能一键回到皮肤原色。

# 预览 {#preview}

中间的 3D 视图就是预览，改什么马上能看到。

- 鼠标拖动旋转，滚轮缩放。`F` 或「对准选中」把镜头对准选中的东西。
- 小键盘：`1` 前、`3` 右、`7` 上，加 `Ctrl` 看反面；`5` 切换透视/正交；`0` 对准选中。
- 视图下面的「模拟开火」「模拟击杀」等按钮模拟游戏事件：动态图层、挂件特效和音效会照游戏里的规则播放。
- 视图右上角的小方块切换前后左右顶底视角；左下角能调灯光、发光的泛光效果，还能自动旋转。

预览尽量贴近游戏，但最后以游戏里为准。装进游戏后可以在「应用到游戏」旁边的「更多」里点「检查与游戏一致」，对比游戏自己组装的枪和预览。

# 保存、导出、装进游戏 {#save}

**保存**

- 每次改动后约 1.5 秒自动保存到编辑器的数据文件夹，状态栏显示「已自动保存」。
- `Ctrl+S` 或卡片「更多」→「保存为文件…」另存一份 `.forgeskinproj` 工程文件；`Ctrl+Shift+S` 另存为一个新皮肤。
- 「版本快照」能留几个命名版本，随时回去。`Ctrl+Z` / `Ctrl+Y` 撤销和重做。

**装进游戏**

1. 右上角选**游戏配置档**（r2modman 的配置档，要先装 BepInExPack_GTFO）。列表里没有就点「选择文件夹…」自己加。
2. 点**应用到游戏**（`Ctrl+Enter`）。编辑器会按需装好插件、打包、装进配置档，并设成这件装备在游戏里用的皮肤。
3. 游戏开着时，改动大约一秒就刷新进游戏；没开的话下次启动游戏生效。「更多」里打开「自动应用」后，游戏开着时每次改完会自动再装一次。
4. 进游戏，在**大厅点 SKINS**，就能看到并切换你的皮肤。

「更多」→「已安装的皮肤…」可以看、启用或删除配置档里装过的皮肤。

**分享给别人**（在「发布」菜单里）

- **检查**：导出前把每个皮肤过一遍，列出要修的问题。
- **导出皮肤包…**：得到一个 `.forgeskin` 文件。
- **导出为 Thunderstore 皮肤模组…**：做成能上传 Thunderstore 的模组，可以放任何装备的皮肤。三种做法：
  - **ForgeSkin**：带全部效果，由 ForgeSkin 插件应用。
  - **Skins：每个皮肤一组**：给装了 Skins 库的玩家。每个皮肤各是一个皮肤组，同一把武器可以放几个，玩家在游戏里挑。
  - **Skins 枪包**：整个模组一个皮肤组，给每把武器选一个皮肤（或「不放进」）；玩家给某把武器选这个枪包，就换上你给它选的皮肤。几把武器共用同名材质时，导出会写上游戏贴图名来区分；贴图也一样、分不开的会列在清单里。
  - Skins 只带静态贴图和材质参数。动态图层、附件、音效、部件调整、磨损阶段、玩家颜色带不上；物品皮肤（医疗包等）Skins 不支持，会被跳过；不采样底色贴图的 BlendHS 材质会写上换成装备着色器，没给的法线、金属度贴图用宏补齐。凡是没带上或被改写的，导出后都会弹出清单。
  - 要导出别的武器的皮肤而它带涂装时，编辑器会临时切到那把武器烘焙涂装，导完切回来。
- **直接改游戏文件**：不用插件，只把贴图和材质参数写进游戏文件（会先备份，可以还原）。

# 常见问题 {#faq}

**进游戏后皮肤糊了**

- 最常见的原因是游戏设置里的**贴图画质不是最高**。这时 SKINS 界面右侧会有一行黄字提醒，说贴图只显示原尺寸的几分之一。把游戏的贴图画质调到最高就好。
- 也看看「应用到游戏」旁边「更多」里的输出尺寸，是不是选了 1K 这种小尺寸，或者原图本身就小。

**皮肤包读不了**

读不了的包不会生效，SKINS 界面右侧会用红字列出包名和原因。常见原因：

- 少了文件：包里写到的图片、声音或模型不在了。重新「应用到游戏」或重新导出。
- 图片坏了或太大：只认 PNG 和 JPEG，单边不能超过 8192 像素。
- 声音坏了：声音要能转成 Ogg，最长 10 秒。
- 路径不对：包里的路径不能是绝对路径，也不能带 `..`。一般是手改过包，用编辑器重新导出。
- 插件太旧：编辑器提示 ForgeSkin 或 ForgeCore 太旧时，在 r2modman 里把它们更新到最新。

**点了应用到游戏，游戏里没变化**

- 看右上角选的是不是你玩的那个配置档。
- 游戏开着时插件需要更新的话，要先关一次游戏，再点一次「应用到游戏」。
- 每件装备只有一个皮肤在用：在皮肤卡片上看是不是标着「游戏中」，或者到游戏大厅的 SKINS 里切过去。

**想再走一遍新手引导**：设置 → 重新开始新手引导，或者这个教程页左下角的按钮。再走一遍会新建一个练习皮肤，已有的皮肤不受影响。
